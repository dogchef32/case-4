# Кейс-задача № 4 — интерактивный калькулятор

Учебная практика: технологическая (проектно-технологическая).

## Как запустить

**Откройте файл `index.html` двойным щелчком в любом современном браузере.** Интернет и установка дополнительных программ не нужны.

Файлы `style.css` и `script.js` должны находиться в той же папке, что и `index.html`.

## Функциональность

- Два поля для ввода чисел.
- Четыре операции: сумма, разность, произведение и деление.
- Вывод результата на странице.
- Проверка пустых полей и некорректных значений.
- Отдельное сообщение об ошибке при делении на ноль.
- Поддержка десятичных дробей с точкой и запятой.

## Проверка

1. Введите `10` и `2`: кнопки должны показывать `12`, `8`, `20`, `5` соответственно.
2. Введите `abc` вместо числа: появится сообщение об ошибке.
3. Введите `0` во второе поле и нажмите «Деление»: появится сообщение о делении на ноль.

## Структура

- `index.html` — интерфейс; **открывать этот файл**.
- `style.css` — оформление.
- `script.js` — логика калькулятора.
